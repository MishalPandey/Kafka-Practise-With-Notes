Kafka Using CLI and Docker.



1--> Check- https://kafka.apache.org/quickstart/ 

2--> run: docker pull apache/kafka:latest
     output: 
		It will pull image of kafka
	 
3--> run: docker run -d --name kafka -p 9092:9092 apache/kafka:latest
     output: 7d57b8099cef40136470c2cfbe081c63cebc5a6469f30fb17ed219b2b0c760e7
		It will Run Kafka container
		-p HOST_PORT:CONTAINER_PORT

4--> run: docker exec -it kafka bash
     output: We are inside kafka container 
	 

5--> Create a Topic in Kafka inside container
	  run: kafka-topics --create --topic my-topic --bootstrap-server localhost:9092 --partitions 3 --replication-factor 1

      use: /opt/kafka/bin/kafka-topics.sh --create --topic my-topic --bootstrap-server localhost:9092 --partitions 3 --replication-factor 1
	  
	  output: Created topic my-topic.
	  
	  Why /opt/kafka/bin/?
		- /opt/kafka/ → Kafka installation directory.
		- bin/ → Contains Kafka command-line tools.
		- kafka-topics.sh → CLI tool to create, list, and describe Topics.

		Explanation:
			- `--create` → Creates a new Topic.
			- `--topic my-topic` → Topic name.
			- `--bootstrap-server localhost:9092` → Kafka Broker address.
			- `--partitions 3` → Creates 3 Partitions.
			- `--replication-factor 1` → One copy of each Partition (no additional replicas).

		Verify Topic creation: kafka-topics --list --bootstrap-server localhost:9092

7--> See list of Topics:
			/opt/kafka/bin/kafka-topics.sh --list --bootstrap-server localhost:9092
			or 
			docker exec -it kafka /opt/kafka/bin/kafka-topics.sh --list --bootstrap-server localhost:9092

8--> Instead of going inside container and then running command, we can directly write like this to create a topic.
		run: docker exec -it kafka /opt/kafka/bin/kafka-topics.sh --create --topic my-new-topic --bootstrap-server localhost:9092 --partitions 2 --replication-factor 1
